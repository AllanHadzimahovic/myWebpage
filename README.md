# Allan — Portfolio

Personal portfolio site built with **Vite + React**.

Working directory: `Documents/myWebpage`

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Content

Edit these files to update the site without redesigning pages:

- `src/data/profile.js` — name, bio, skills, contact links
- `src/data/projects.js` — project cards and featured flags

## Layout

v1 uses a **single scrolling page** with sticky section nav (Intro → About → Projects → Contact), inspired by clear personal sites like [milo.gg](https://milo.gg/) — clarity first, personality second.
